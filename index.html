A+B Free Shipping Logic

✓ Function is active and ready to use

How it works:

  • Add metafield custom.ab_group to your products
  • Set value to Free-gift for A-type products (free items)
  • Set value to None-free for B-type products (paid items)
  • When cart contains both types, free shipping will be applied to A-type products

Configuration:

No additional configuration needed. The function is automatically applied during checkout.
